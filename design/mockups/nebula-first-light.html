Every star is born in a cloud like yours.

The wait becomes the point. First drops don't start the story — they ignite inside the nebula the user spent months building. From here, output adds brightness to what's already theirs. Skies don't go backward.

✦Stars mark sessions, never milliliters

The sky rewards the only thing the user controls: showing up. Day one earns light. A user three months in with zero drops has a sky full of stars — because they earned a sky full of stars.

✦The nebula is the nursery

Every session adds a wisp of gas and color. The cloud visibly deepens with consistency, so the pre-lactation months read as growth, not absence. This is real astronomy: stars form inside nebulas, slowly, and then all at once.

✦Skies don't go backward

Output adds brightness; it never subtracts. A low-supply day leaves the sky exactly as beautiful as the night before. There is no failure state anywhere in this design — only accumulation.
